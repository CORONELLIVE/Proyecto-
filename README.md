# FORMA — A tu manera

Concepto de tienda de calzado en español, responsive y PWA. HTML, CSS y JavaScript sin dependencias ni compilación.

## Funciones
- Catálogo con filtros por categoría y ordenación por precio.
- Detalle con selector de talla EU 36–44.
- Bolsa con cantidades, eliminación y persistencia local.
- Instalación PWA, iconos propios y catálogo completo sin conexión después de la primera carga y activación del service worker.
- Diseño adaptable, navegación por teclado, diálogos nativos y soporte para movimiento reducido.

## Ejecutar
Desde la raíz: `python -m http.server 8080`. Abrir http://localhost:8080.

## Publicar
Importar este repositorio en Vercel como proyecto estático (Framework: Other). No requiere comandos de instalación ni compilación. `vercel.json` configura salida y cabeceras.

## Alcance
Los productos, nombres, precios y disponibilidad son ilustrativos. La prueba de pedido no envía pedidos, no solicita datos ni procesa cobros. No incluye backend, stock real, cuentas ni pasarela de pagos. La bolsa se conserva en el navegador del dispositivo.
